# 按文件名或路径打开文件

[English](file-location.md)

macOS 编辑器在文件标签下方提供文件输入栏。点击当前路径，替换为文件名或路径，然后按 **回车** 或点击 **Open**。**File → Open File by Name or Path…** 和 **⌥⌘O** 可以聚焦并全选输入框。已有的 **⌘L** 跳转行号快捷键保持不变。

支持的输入：

| 输入 | 解析方式 |
| --- | --- |
| `README.md` | 在已打开文件和项目索引中精确匹配完整文件名；重名时列出完整路径供选择。 |
| `src/main.swift` | 相对当前项目文件夹；没有项目时，相对当前已保存文件的所在文件夹。 |
| `/tmp/notes.md` | 本地绝对文件路径。 |
| `~/Documents/notes.md` | 当前用户目录下的路径。 |
| `file:///tmp/meeting%20notes.md` | 本地文件 URL，支持百分号编码的空格和 Unicode。 |

直接输入路径文字，不需要 shell 引号。不会展开 shell 变量或表达式。文件名按精确拼写匹配，部分名称搜索继续使用 **Quick Open（⌘P）**。复用已有后台项目索引，不会每次输入字符都扫描目录；名称查找同样受项目索引范围限制。显式路径可以打开项目索引之外的文件。

已打开文件直接切换到现有缓冲区，保留未保存内容。切分布局中，文件打开到活动区域，另一侧视图保留。输入栏跟随活动标签、区域、另存为和返回主页。打开项目文件沿用现有的侧栏自动定位。路径不存在或输入非法时保留输入便于修改，并显示通知；文件夹路径提示使用 Open Folder。文件解码或读取错误沿用正常错误对话框。该入口不会创建或保存文件。

**Escape** 取消输入，恢复当前路径及编辑焦点。隐藏文件标签或打开 Markdown 预览时仍可使用。专注模式隐藏该栏，**⌥⌘O** 在输入时临时显示，Escape 或返回编辑器后再次隐藏。深浅主题、窄窗口均使用原生 AppKit 控件。

`FileLocationResolver` 负责路径解析、精确名称查找和候选去重；`FileLocationBar` 管理输入与显示状态；`EditorWorkspace` 将解析后的 URL 交给已有文档打开流程，并激活当前区域。输入栏仅保存字符串，不持有文档对象或文本存储。

原生验收使用独立文件和测试应用，覆盖回车/Open、快捷键、Unicode/URL 路径、重名选择、未保存缓冲区复用、非法输入、侧栏跟随、切分、预览、专注/显示、窄窗口主题和窗口隔离。该功能在 macOS 实现，不声称 Windows 等价能力或新的延迟/RSS 测量。参见[开发指南](development.zh-CN.md)和[编辑区切分](editor-splits.zh-CN.md)。
