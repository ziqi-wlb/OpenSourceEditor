## 当前 0.9.10 状态

macOS 0.9.10 build 23 的聚焦验收通过 167 项。2026-10-31 使用相同已验收程序复查产品 UI，77 项通过，分隔条拖动及渲染标题片段导航两项失败。需要定位产品/样本原因并完成完整 UI 门禁，无界面检查及旧版通过记录不能消除这一缺口。

工作区恢复、主页、独立编辑区切分、文件标题输入、图片及列表视口稳定性均已实现。真实输入法、原生文件面板成功操作、长期/系统中断恢复、无障碍及物理平台验收仍需分别完成。最新问题、证据和实施顺序见[当前差距分析](current-gap-analysis.zh-CN.md)；[日常使用分析](daily-use-gap-analysis.zh-CN.md)保留 0.7.0 历史基线。

Source Editor 为独立编辑器，以熟悉的 Sublime/VS Code 工作流指导交互，不包含其代码或资产。macOS 与 Windows 实现和验证分别记录。日常开发/笔记差距、优先级与场景见 [历史差距分析](daily-use-gap-analysis.zh-CN.md)。

## 验收标准

稳定发行要求可恢复文件操作、Unicode/IME、可靠撤销、有限后台工作、明确容量覆盖、键盘/无障碍、便携构建、配置说明、真实 GUI 回归与资源测量。功能存在不等于工业级就绪。

| 范围 | 已有能力 | 仍需验收 |
| --- | --- | --- |
| 文件 | 严格解码、原子保存、冲突/取消、重启元数据、默认草稿、恢复/丢弃/外部保护 | 原生选择成功、长会话、系统/硬件中断与断电 |
| 编辑 | TextKit、多选、撤销、缩进、行/注释、共享拆分 | 实际 IME、矩形选择、大文件引擎、丰富语法 |
| Markdown | 源/预览/并排、模板、列表/任务、图片、标题、HTML | 长时写作、更完整语法、真实滚轮/无障碍 |
| 项目 | 懒树、创建/移动/废纸篓、FSEvents、Quick Open、后台字面搜索 | 忽略策略、正则替换、脏文本搜索、外部差异 |
| 扩展 | 一次性 Python/构建 | LSP 生命周期、片段、扩展版本政策 |
| 发行 | Universal 源码/程序、本地安装、Markdown 关联、双语版本说明 | 签名公证、物理 Intel |
| Windows | 功能较少的 Win32 实验 | 原生 UI/性能及功能补齐 |
| 无障碍/布局 | 原生有名称控件、显示开关和专注全屏 | VoiceOver、纯键盘、高对比、多屏/跨 Space |

## 历史实现阶段

0.9.3 增加双语说明、作者联系及原生离线版本信息；工作区提供标签/状态/行号隐藏与专注模式，原生全屏由系统控制菜单/Dock，退出恢复原布局。匹配的 `bilingual-focus-093-verified` 验收为 646 项通过、13 项明确跳过，也验证缩窄原生窗口后的长句换行；长期稳定性仍需专项验收。

0.9.2 项目树跟随当前文件展开/选择/滚动，预览/导出移除自动 Contents。Universal 验收616通过/13跳过；GUI在ARM，Intel版本入口在Rosetta。

0.9.1 文档拥有基础样式、复用当前pane、保留导入session、采用有说明SF Symbols；604/13。详见 [显示性能](presentation-performance.zh-CN.md)。0.9.0 默认保留草稿、真实退出恢复、明确丢弃、失败取消及字体持久化，598/13。见 [架构](architecture.zh-CN.md)、[功能](features.zh-CN.md)、[0.9.0资源](release-090-performance.zh-CN.md)。八文件heartbeat定向改善，但同步打开与约0.2s切换批量成本仍在。

0.8.0 实现偏好/工作区恢复、快照发现、事件监控、范围约束文件管理、笔记录入和限额后台搜索；干净外部更新重载，脏缓冲区保留，拒绝不完整/过期替换。见 [实施](daily-use-implementation.zh-CN.md)。

0.7.0 增加Markdown及项目搜索，Foundation拥有解析，转义HTML，按需WebKit，串行防抖拒绝旧代次；预览/导出未保存内容，切换不改变文本/撤销。QuickOpen/项目搜索共用有范围报告的遍历，打开结果复核源码；构建/测试/预览助手隔离用户安装。
