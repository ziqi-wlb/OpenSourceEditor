# 工作区主页与侧栏按钮（macOS 0.9.5）

[English](workspace-home.md)

新窗口和只打开文件夹的工作区显示原生主页，不再自动创建空白 Untitled 文件。可从侧栏选择文件、点击最近记录或快捷按钮开始工作。关闭最后一个文件标签后返回主页；New File（`⌘N`）才明确创建编辑缓冲区。已有文件打开时再切换文件夹，会保留这些文件和当前编辑内容。

| 主页操作 | 结果 |
| --- | --- |
| New File | 创建一个未命名文件，焦点进入正文编辑 |
| Open File… | 通过正常文件选择和文档打开流程打开文件 |
| Open Folder… | 选择项目文件夹，没有文件打开时保持主页 |
| Markdown Note | 创建 Markdown 文档，使用现有预览与笔记工具 |
| Quick Open | 快速查找当前项目文件（`⌘P`） |
| Find in Folder… | 打开项目内容搜索（`⇧⌘F`） |
| Recent Files / Recent Folders | 分别打开最近五个文件或文件夹之一 |

选择文件夹前，项目专用操作处于禁用状态。File 菜单保留完整最近记录。主页展示项目名称，适配暗色与浅色主题，窄窗口从双列改为单列；纵向滚动保证小窗口中仍可访问全部按钮与历史记录。选中真实文档后才显示编码、缩进和语法控件。主页本身没有文档文本、修改标记、保存提示或草稿；存在文档后才可 Save Session。

点击项目标题旁的侧栏图标可隐藏目录，窗口标题栏中的对应图标始终可用于重新显示。两个按钮复用 **View → Toggle Sidebar** 和 **⌃⌘B** 快捷键。隐藏目录后主页面扩大；隐藏文件标签或状态栏时，标题栏图标仍可使用。原生全屏由系统控制标题栏显示，可将鼠标移到顶部访问窗口控件。显示状态仍遵循[工作区恢复](workspace-restoration.zh-CN.md)。

`EditorWorkspace.documents` 只包含真实文档，列表为空时展示 `WorkspaceHomeView`，释放编辑视图和 Markdown 预览。主页使用 AppKit 标签、SF Symbols、按钮和滚动视图，不创建 WebKit 实例或新定时器。类型化显示键包含项目身份、有限的最近记录与主题，避免重复重建。应用持有最近历史，工作区持有操作、文件选择与焦点；按钮复用已有流程，不自行解释路径或写入文件。

原生检查覆盖文件夹启动、明确新建/打开/笔记、最近入口、菜单状态、按钮隐藏/恢复侧栏、主区域变宽、隐藏编辑控件、主题、窄窗口滚动及重启。成功选择文件采用注入的 URL 测试数据，随后走生产打开流程；原生选择器成功选择仍需独立人工验收。检查原文件字节不变，原生内容视图截图保存在对应 `.build/test-results/`。这些检查不代替实体 Intel GUI 或 Windows 等价能力验证，本轮不声称新的内存或延迟对比。

参见[布局](layout.zh-CN.md)、[开发指南](development.zh-CN.md)、[架构](architecture.zh-CN.md)和[版本说明](../RELEASE_NOTES.zh-CN.md)。
