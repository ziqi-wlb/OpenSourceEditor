# 回车、滚动与文字颜色

[English](typing-stability.md)

0.9.10 修复 Markdown 有序列表回车时视口跳动的问题。回车继续编号，光标留在新行，原来的编辑位置保持可见。Tab、普通文本/代码回车及自定义编辑的撤销/重做使用同一条光标事务路径；切分中的其他视图保留各自的光标和滚动位置。

原有命令生成完整文本后，`EditorDocument` 把整个 `NSTextStorage` 替换掉，即使实际仅插入一个换行。这会使 TextKit 丢失未变化内容的排版，收缩或移动视口。文档拥有者现在按 UTF-16 的相同前后缀确定变化范围，只替换该片段；边界避开代理对中间，保留其他内容的属性与排版。原生光标事务完成后确保主要光标可见。读取新文件和显式重新加载仍允许替换整个文档。

命令仍会生成完整结果，撤销仍保留原来的文本快照；本修复不把命令计算或撤销内存描述为恒定开销。它减少的是 TextKit 的全文件排版失效与未变化文本属性覆盖。

撤销和保存基线需要保留的文本，现在显式复制存储中的 UTF-16 字符为拥有独立内容的 Swift 字符串，保证局部修改后的快照生命周期。诊断记录也使用同一文档边界，避免后续输出把实时存储桥接值当作先前文本。长列表回归检查保留文本、脏状态，以及撤销/重做返回保存基线的行为。

Markdown 曾使用所有语言共享的代码数字、字符串规则，列表编号、日期或引号正文会在延迟高亮后变色。高亮拥有者现在将 Markdown 正文排除在字面量规则之外，保留标题和注释高亮。源代码的数字/字符串及 HTML/XML 属性保留原有配色。

原生检查覆盖长文档中的 Return 按键、即刻和高亮完成后的滚动位置、编号/光标、一次撤销/重做、深浅主题、Tab 与同文档切分，以及 `.txt`/`.swift` 回车。文档核心检查涵盖代理对、组合字符、emoji 序列、CRLF 和不变段落的字体保留。真实硬件输入法和长期输入/滚动时序仍需额外手动验证。复现命令见[开发指南](development.zh-CN.md)，已执行结果见仓库验收记录。

## 已执行的观测

共同样本使用 300 条有序列表、1000×650 的内容区域，在第 275 条末尾按 Return。基线使用 0.9.9 运行时源码并增加测试入口；最终样本还在测量前等待初始焦点与排版完成。

| 观测 | 0.9.9 | 0.9.10 |
| --- | --- | --- |
| 回车前滚动 Y（AppKit 点） | 5245.5 | 5245 |
| 立即回车后 | 3425 | 5245 |
| 延迟高亮完成后 | 3439 | 5245 |
| 字符修改范围（起点、长度） | 0、7003 | 6402、6 |
| 列表数字颜色 | 代码数字橙色 | 正文颜色 |

专项验收 `typing-0910-delivery` 记录 **167 项通过**：20 项核心、83 项文档/设置、20 项原生输入和 44 项切分。它复用 `typing-0910-snapshots` 中这些已执行的检查，发布/测试二进制未变化。深浅主题截图已检查。Universal 两切片编译，Intel 版本入口在 Rosetta 运行，GUI 在 Apple Silicon 验证。29 对中英文指南及导出源码的可移植性另外检查。

更广泛的 `typing-0910-snapshots` 运行仍为**失败**：Markdown 产品套件报告分割条拖动几何和渲染标题链接导航两项失败，未继续执行综合 UI 和最后的多窗口 Quit。此前的窗口焦点/菜单失败、初始排版不稳定及文本/撤销差异记录均保留；修复明确建立测试焦点/排版，并让保留文本拥有独立内容。独立最小存储样本没有复现桥接快照观测，因此不声称已证实每项历史失败的原因。失败运行没有改写为全套通过。开发入口现支持 `--suite typing`，避免重复执行无关检查。

这是光标与排版稳定性的实测。本轮未重新测量输入延迟、CPU、RSS、持续滚动或实体 Intel/Windows GUI。日志、快照、截图和安装证据保存在忽略的 `.build/test-results/` 目录中。
