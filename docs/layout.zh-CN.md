# 布局与专注模式（macOS 0.9.3）

[English](layout.md)

View 菜单可独立显示/隐藏左侧目录、文件标签栏、状态栏和行号，勾选表示当前可见。命令面板也提供这些操作。隐藏状态栏后，菜单仍可设置编码、缩进等信息。

| 操作 | 入口与快捷键 |
| --- | --- |
| 左侧目录 | View → Toggle Sidebar · ⌃⌘B |
| 文件标签 | View → Toggle Tab Bar |
| 状态栏 | View → Toggle Status Bar |
| 行号 | View → Toggle Line Numbers |
| 原生全屏 | View → Toggle Full Screen · ⌃⌘F |
| 专注模式 | View → Toggle Focus Mode · ⌥⌘Z |
| 恢复专注前布局 | 源码编辑中 Escape，或再次 ⌥⌘Z |

专注模式记录当前布局，隐藏目录、文件标签、状态、行号、Markdown 工具栏、查找与输出，并在需要时进入原生全屏。编辑区域填满空间，不留空白顶部/底部占位。通知仍可显示；明确打开查找或构建时可显示对应控件。文本、选区、撤销、快捷键和右键编辑保持原有语义。

全屏由系统自动隐藏菜单栏与 Dock，鼠标移到屏幕顶部/底部可访问；不修改全局 macOS 偏好。已有原生工作区标签暂时隐藏，工作区不被关闭。窗口动画期间暂时禁用重复的全屏/专注切换。

退出恢复进入前的可见性和拆分比例。若专注模式主动进入全屏，则退出时也离开；若进入前已经全屏，则保持原有全屏。通过原生全屏退出同样恢复布局。输入法组合态的 Escape 仍交给 IME。

普通模式下目录、标签、状态与行号选择写入工作区，重启恢复；旧状态缺少可选字段时默认显示标签/状态/行号。专注期间持久化原布局和正常窗口位置，不会在重启时突然回到隐藏控件的全屏状态。布局记录不改变文本或覆盖原文件。

工作区拥有显示状态与一份临时专注快照；frame 布局对隐藏控件使用零高度，原拆分几何处理隐藏 pane。全屏完成/失败回调管理过渡，不增加全局菜单计时器或常驻线程。新 pane 消费工作区的行号状态。见 [架构](architecture.zh-CN.md)、[文档工作区](document-workspace.zh-CN.md) 与 [版本说明](../RELEASE_NOTES.zh-CN.md)。

原生验收检查独立开关、实际全屏、菜单/Dock 选项、布局恢复、编辑焦点和文本不变；截图和实际计数与对应发行验证保留。不能推导跨 Space、多显示器、物理 Intel 或 Windows 功能等价。

最终 `bilingual-focus-093-verified` 验收通过 646 项、明确跳过 13 项合同向量；其中 79 项工作区 UI 包含上述场景，生产摘要和专注模式截图匹配 macOS 0.9.3。Universal 两切片编译，Intel 版本入口在 Rosetta 通过。本次未新增运行内存或响应延迟测量。

Preferences → Remember Previous Workspace 默认开启，同时恢复文件夹与文件标签。关闭后重开进入空白窗口，保留可手动恢复的草稿与独立的最近文件夹历史。参见[工作区恢复](workspace-restoration.zh-CN.md)。
