# 图片预览

[English](image-preview.md)

通过 **File → Open**、项目目录、Quick Open、可点击的窗口标题、Finder **打开方式**或命令行文件参数打开图片，会得到一个只读文件标签。图片与文本可以放在不同切分区域；选中图片时，标题、目录选择和文件右键操作都会跟随。

工具条提供 **Fit（适应窗口）**、**100%（原始尺寸）**、**−**、**+** 和 **Reload（重新加载）**。Fit 将图片显示在当前区域内，不放大小图片。100% 按源图片像素尺寸映射到 AppKit 点。预览取得焦点后，可用 `+`/`−` 缩放、`0` 适应窗口、`1` 原始尺寸，也提供捏合手势入口；标准滚动条和滚动操作用于查看放大后的图片。**View → Image Preview** 提供相同操作。棋盘格表示透明区域，控件旁显示尺寸、文件大小与多帧信息。图片或文件标签右键支持复制路径、打开所在目录、目录定位、关闭和切分；图片区域还提供缩放及重新加载操作。

PNG、JPEG/JPG/JPE、GIF、BMP、TIFF、HEIC/HEIF、WebP、ICO 扩展名交给 macOS ImageIO 解码，具体格式可用性取决于系统。多帧 GIF/TIFF/ICO **仅显示第一帧或第一页**，暂未实现动画播放和翻页。SVG 仍作为源码编辑；本轮不包含 PDF、音频或视频预览。不发起远程预览请求，不增加第三方依赖。

图片采用只读预览。图片标签不提供保存、另存为、文本查找、编码和缩进操作；文档核心也拒绝文本保存，防止二进制图片被空缓冲区覆盖。修改原图需使用图片编辑器。重新加载和文件系统事件会更新预览。恢复工作区和 Save Session 只保存图片文件引用，不写入图片字节；图片引用不可用时报告错误。图片不会产生未保存的文本草稿。重新选中或恢复图片时默认 Fit，缩放状态属于当前可见区域。

`EditorDocument` 负责文件类型，`EditorImageAsset` 负责图片元信息。图片字节不进入 `NSTextStorage`，不进行文本解码。`EditorPane` 对图片显示 `ImagePreviewView`，文本继续使用原有 TextKit 视图；活动区域的文件路由仍归 `EditorWorkspace`。工作区/会话中的可选图片标记保持旧文本记录兼容，也让改成其他扩展名的图片引用按图片恢复。

ImageIO 缩略解码在共享队列中进行，最多 **两个并发任务**。每个可见区域保留的栅格最长边不超过 **2048 像素**，正方形上限约 **16 MiB RGBA 像素**；隐藏标签只保留文件元信息，关闭或取消后的视图拒绝迟到结果。大图的 100% 显示会放大受限分辨率预览，不解码完整原图细节，工具条会说明该情况。输入限制为 **128 MiB**、**6400 万源像素**及**单边 100,000 像素**。这些用于限定支持的工作负载；解码器工作区和合成器内存可能高于保留栅格大小，不能把该上限当作进程 RSS 实测。

原生检查在忽略的 `.build/` 下生成图片，覆盖 PNG/JPEG/GIF/BMP/TIFF、EXIF 方向、受限解码、原件保持、原生控件/右键、深浅主题、混合切分、真实文件事件、关闭后视图释放及快速打开/关闭。独立进程检查工作区和显式会话恢复。HEIC/WebP/ICO 具体解码、真实触控板手势、实体 Intel GUI 与 Windows 等价能力需另行验收。复现命令见[开发指南](development.zh-CN.md)，已执行结果见仓库验收记录。

## 本地资源测量

0.9.9 Universal 可执行文件为 **4,582,080 字节**，应用目录内文件合计 **5.01 MiB**（不是磁盘分配空间或压缩包大小）。同一份通过验收的发行可执行文件复制到独立应用身份中，分别打开 0、1、16 个图片标签，仅一个区域可见。工作负载为调整尺寸后的合成透明 PNG，4096 × 2048 像素；每个独立进程运行约 5 秒，每 250 ms 采集 `ps` RSS 与累计 CPU 时间，并保存 `vmmap` 和窗口截图。

| Image tabs / 图片标签 | Last sampled RSS (MiB) / 末次 RSS | Sampled peak RSS (MiB) / 采样峰值 | CPU time / CPU 时间 |
| --- | --- | --- | --- |
| 0 | 49.6 | 60.7 | 0:00.20 |
| 1 | 69.4 | 69.4 | 0:00.27 |
| 16 | 99.7 | 315.2 | 0:02.27 |

这是本机短时样本，包含应用、解码器和界面内存；受系统页缓存、内存压缩和其他进程负载影响。采样峰值不是完整瞬时峰值，也不包含 WindowServer 的独立内存。没有此前等价图片预览可作优化前对照，不把这些数值描述为提速或长期无泄露证明。原生检查另外验证关闭后的视图释放与 16 次快速打开/关闭。首次打开延迟、大型真实照片、持续滚动、长期循环及多可见区域 RSS 尚未测量。

本地证据位于 `.build/test-results/image-preview-099-accepted/resources/`。复测时使用独立应用身份以隔离个人工作区，通过 `ps -p <pid> -o rss= -o time=`、`vmmap -summary <pid>` 采集，并确认原生窗口显示了预期图片。
