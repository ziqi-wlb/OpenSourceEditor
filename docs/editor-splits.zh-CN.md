# 编辑区切分（macOS 0.9.6）

[English](editor-splits.md)

点击窗口标题栏的切分图标，或使用 **View → Split Editor**（`⌥⌘2`），将当前文件显示为两个编辑区域。**Split Right** 左右排列，**Split Down** 上下排列；拖动分隔线调整比例。两个区域分别保留选区与滚动位置，显示同一文件时共享编辑内容和撤销记录。

切分工具栏为两侧各提供一个文件选择框，以及方向切换和 **Single Pane** 按钮。可以分别选择已经打开的文件。点击正文使对应区域成为活动区域；全局文件标签、项目侧栏、保存、查找和文档设置均跟随该区域。打开文件或选择全局标签仅替换活动区域。**View → Open in Other Pane** 在另一区域选择下一个已打开文件，需要时自动切分；只有一个文件时，两侧显示同一文件。

| 操作 | 入口 |
| --- | --- |
| 切分 / 恢复单区域 | 标题栏图标或 `⌥⌘2` |
| 左右排列 | View → Split Right、文件标签右键或切分工具栏 |
| 上下排列 | View → Split Down、文件标签右键或切分工具栏 |
| 切换活动区域 | 点击对应正文或 `⌥⌘3` |
| 合并为单区域 | Single Pane 按钮或 `⌥⌘1` |
| 在另一区域打开另一个已有文件 | View → Open in Other Pane |

Single Pane 保留活动编辑视图、光标和全部文件标签，不会保存或关闭文件。关闭文件会从两侧移除对应文档，保留的文档接替被移除区域；关闭最后一个文件回到主页。主页禁用切分入口。工具栏适配窄窗口与深浅主题，专注模式会随其他控件一起隐藏它。Markdown 完整预览在内容区渲染活动文件，返回 Edit 后恢复源文件切分；新建或切换切分方向会进入正文编辑模式。

开启 Remember Previous Workspace 后，工作区恢复包含切分方向、比例、活动区域、各区域文件、选区和滚动位置。Save Session 与草稿恢复同样保留区域状态，包含未保存文档。旧的会话/工作区 JSON 保持可读：只有原 `split` 开关、没有可选布局元数据时，恢复为选中文件的两个视图。缺失文件仍遵循既有文件恢复与草稿保护规则。

`EditorWorkspace` 拥有活动文档、另一侧文档与切分几何。每个 `EditorPane` 拥有 TextKit 布局管理器和视口，文档拥有 storage、撤销和磁盘身份。焦点在统一入口更新活动文档，使菜单、设置和编辑使用同一所有者。另一侧更换文件或切换方向时复用未变更的视图，合并时移除非活动布局管理器，不复制文本。原生工具栏只持有有限的文件选择，不新增线程或定时器。`SavedEditorLayout` 共用于工作区/会话序列化，校验两个区域和有限几何；文档序号与文件路径分开，以支持草稿恢复。

原生验收覆盖标题栏/菜单/工具栏、不同文件、同文件输入与撤销、独立滚动、活动区域路由、光标/视图保留、真实分隔线拖动、窄窗口、主题、JSON 会话/工作区恢复、非法元数据、资源释放及最后文件回到主页。自动检查使用独立文件与测试应用身份。实体 Intel GUI 和 Windows 等价能力仍未验证，本轮不声称新的内存或延迟基准结果。

切分工具栏隐藏时仍更新文件选择框持有的文档，退出切分时清空这些引用。关闭最后一个文件后，停留在主页也会释放该文档。弱引用生命周期检查覆盖这一所有权规则，不代表进程 RSS 测量。
