# Source Editor Release notes

[中文](RELEASE_NOTES.zh-CN.md)

Author: ziqi-wlb · [550461053@qq.com](mailto:550461053@qq.com)

## 0.9.5

- Show a native workspace home for new windows and folder-only projects, with quick file/note/search actions and recent entries.
- Return home after closing the last file tab; create an untitled buffer only through an explicit New File action.
- Add sidebar buttons in the project header and titlebar; adapt the home to dark/light themes and narrow windows.

## 0.9.4

- Restore the last closed workspace, including folder-only projects and sidebar expansion, selection and scroll position.
- Add Remember Previous Workspace, enabled by default; disabling it starts blank while retaining manually recoverable drafts and recent folder history.
- Add Reopen Last Folder and Open Recent Folders to menus and the command palette; preserve layout after draft recovery.

## 0.9.3

- Add bilingual project documentation, with language links for usage, architecture, development, extensions, performance and validation.
- Add a native project introduction with author contact information and English/Chinese switching.
- Show release notes offline from the application menu, including when no editor window is open.
- Add independent sidebar, file-tab, status and line-number visibility controls, with normal layout restored on restart.
- Add Focus Mode with native fullscreen, automatic menu/Dock hiding and Escape restoration of the prior layout.

## 0.9.2

- Follow the active project file in the sidebar: expand ancestors, select and scroll to the file while preserving editor focus.
- Keep other folders expanded and follow the current file when a hidden sidebar is shown again.
- Start Markdown preview and HTML export directly with the document body; retain source-written fragment links.

## 0.9.1

- Share document display styles and reuse the active pane to reduce redundant text restyling.
- Use labelled native icon buttons and preserve imported session files.

## 0.9.0

- Keep independent drafts on normal close and restore unfinished files and untitled notes after restart.
- Add explicit discard/revert, backup failure retry and persistent installed-font preferences.

## 0.8.2

- Make Outline and the Markdown build shortcut render unsaved content in one step.

## 0.8.0

- Add workspace preferences, file monitoring, sidebar file operations, note templates and bounded asynchronous search.

## 0.7.0

- Add Markdown preview, side-by-side reading, HTML export and project-wide literal search.

## 0.6.2

- Add a user-directory installer and Finder Markdown file associations for the Universal macOS application.
